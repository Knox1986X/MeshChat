# MeshChat

**Анонимный мессенджер без аккаунтов, телефона и доверия к серверу.**
Сквозное шифрование, несколько независимых транспортов, работа офлайн-первым.
Один и тот же код живёт в браузере, как PWA на Android, на Linux и на Windows.

```
        ┌──────────────┐   зашифрованный конверт    ┌──────────────┐
        │   Alice      │  ────────────────────────►  │    Bob       │
        │ Ed25519 keys │  ◄────────────────────────  │ Ed25519 keys │
        └──────┬───────┘                             └──────┬───────┘
               │                                            │
     ┌─────────┴──────────┬─────────────────┬───────────────┴─────────┐
     ▼                    ▼                 ▼                         ▼
  relay (WS/HTTP)   Git-репозиторий   локальная шина          свой транспорт
  zero-knowledge    «бесплатный       (вкладки, LAN)          (Nostr, I2P, …)
  mailbox           сервер из git»
```

Relay видит только 128-битный routing-tag, размер и время. Ни отправителя, ни
получателя, ни текста. Даже если сервер полностью скомпрометирован — читать
нечего.

## Что умеет

| Возможность | Как сделано |
|---|---|
| Анонимность | ключ = аккаунт, никакой регистрации, почты и номера |
| E2E-шифрование | X3DH → Double Ratchet, XChaCha20-Poly1305, Ed25519 |
| Forward secrecy | новый ключ на каждое сообщение, DH-ratchet при каждом ответе |
| Несколько транспортов | relay (WebSocket + long-poll fallback), GitHub-репозиторий, локальная шина |
| Децентрализация | неограниченное число relay, у каждого свой ящик, любой можно поднять на бесплатном хостинге |
| Офлайн | IndexedDB, очередь исходящих, доставка при появлении сети |
| Анти-спам без аккаунтов | proof-of-work, который требует relay |
| Приватность деталей | паддинг до 256 байт, отчёты о прочтении и «печатает» отключаемы |
| Исчезающие сообщения | TTL 1 ч / 24 ч / 7 дней на контакт |
| Файлы и картинки | шифруются и режутся на чанки, до 8 МБ |
| Верификация | 60-значный safety number, сравнение вне канала |
| Локальный слепок | бэкап личности, зашифрованный Argon2id |
| Офлайн-интерфейс | PWA: установка на Android/Windows/Linux, service worker |

## Быстрый старт (60 секунд)

```bash
npm install
npm run build      # собирает UI и single-file relay
npm start          # http://localhost:8787 — приложение + relay + WebSocket
```

Откройте адрес в двух разных браузерах (или один в обычном окне, второй — в
приватном), создайте две личности, поменяйтесь ссылками-приглашениями.
Всё, чат работает: сообщения идут через ваш локальный relay.

Без всякого сервера тоже можно: транспорт **local** работает между вкладками
одного браузера — удобно посмотреть, как всё устроено, до деплоя.

### Полезные команды

```bash
npm run relay        # relay напрямую из TS (без сборки), с hot-reload через tsx
npm run dev          # Vite dev-сервер, проксирует /v1 на localhost:8787
npm test             # 29 тестов: крипто, ratchet, e2e через реальный relay, UI
npm run typecheck    # строгий TypeScript по всему монорепо
npm run build:app    # только UI → packages/relay/public
```

## Транспорты

Транспорт — это просто «курьер», который носит непрозрачные конверты. Добавить
свой (Nostr, Matrix, I2P, USB-флешка, почтовый ящик) = реализовать интерфейс
`Transport` в `packages/core/src/transports/types.ts`.

| Транспорт | Что это | Плюсы | Ограничения |
|---|---|---|---|
| **relay** | `packages/relay` — Node-сервер: HTTP + WebSocket + long-poll | быстрый, push, работает за NAT | нужен хостинг (но есть бесплатные) |
| **git** | GitHub-репозиторий как почтовый ящик: письмо = коммит | совсем бесплатно, постоянно, без своего сервера | задержка = интервал поллинга, виден факт трафика (но не содержимое) |
| **local** | BroadcastChannel | ноль настройки, работает без сети | только один браузер/устройство |
| *(roadmap)* | Nostr / I2P / Bluetooth-mesh | | см. `docs/ROADMAP.md` |

### Git-транспорт — та самая идея «сервер = репозиторий»

1. Создайте **приватный** репозиторий (можно публичный — внутри только шифротекст).
2. Сделайте fine-grained token с правом **Contents: read & write** только на этот репозиторий.
3. В приложении: *Настройки → Git-репозиторий* → owner / repo / branch / token.

Клиент пишет конверты в `box/<routing-tag>/<id>.json` и удаляет прочитанные.
Хелпер для первичной настройки:

```bash
npm run git:init -- --owner you --repo mesh-mailbox --token github_pat_…
```

## Платформы

* **Linux (CachyOS/Arch)** — `npm start` и открыть в браузере; либо поставить как
  PWA из Chromium; либо собрать нативный бандл через Tauri (`docs/PLATFORMS.md`).
* **Windows** — то же самое; PWA устанавливается из Edge/Chrome в меню «Установить».
* **Android** — открыть адрес в Chrome → «Установить приложение». Для настоящего
  APK есть CI-workflow (Capacitor) и инструкция.
* **Docker** — `docker compose up -d`, всё в одном контейнере.

Подробности и пошаговые инструкции: [`docs/PLATFORMS.md`](docs/PLATFORMS.md).

## Что защищено, а что нет

Защищено:

* содержимое переписки и файлов — от relay, провайдера, владельца репозитория;
* компрометация долгосрочного ключа — не даёт читать прошлые сообщения (forward secrecy);
* компрометация ключей сессии — восстанавливается после следующего DH-ratchet;
* подмена ключей сервером — bundle подписан Ed25519 и сверяется с ключом из приглашения;
* спам и забивание бесплатных relay — proof-of-work + rate limit.

**Не** защищено (честно):

* **метаданные**: relay знает тег получателя, время и размер. Кто с кем — нет,
  но корреляция трафика возможна. Для сильной анонимности — свой relay за Tor.
* **локальное устройство**: IndexedDB не зашифрован ключом (в roadmap есть
  passphrase-lock). Захват устройства = доступ к истории.
* **собеседник**: скриншоты, экспорт, «переслать» — вне криптографии.
* **многоустройственность**: пока одна личность = одно устройство.

Полный разбор — [`docs/SECURITY.md`](docs/SECURITY.md).

## Принципы

1. **Нет аккаунта — нет слежки.** Личность — это 32 байта энтропии.
2. **Сервер не должен ничего знать.** Если сервер можно выключить и ничего не
   сломается (кроме доставки) — дизайн правильный.
3. **Криптография — не опция.** Никаких «шифрование в Pro-версии».
4. **Никакой телеметрии, внешних шрифтов и CDN.** Всё лежит в бандле.
5. **Проверяемо.** 29 тестов на крипто и сквозные сценарии идут с каждым коммитом.
