# Деплой relay за 5 минут

Relay — это единственный сервер, который нужен MeshChat. Он **слепой**: пересылает
шифрованные кадры между устройствами и проксирует GigaChat. Сообщения не хранятся.

> ⚠️ **Сначала про токен.** Ты прислал API-токен прямо в чат — он теперь считается
> скомпрометированным. Зайди в Cloudflare → My Profile → API Tokens → **Roll/Delete**
> этот токен и создай новый. Никогда не вставляй токен в переписку: приложение его
> не требует, деплой делается у тебя на машине через `wrangler`, который хранит
> секрет в своём конфиге.

---

## 1. Что понадобится

- **Account ID** Cloudflare (Dashboard → Workers & Pages → справа «Account ID»).
  Одного токена недостаточно — `wrangler` спрашивает и токен, и аккаунт.
- Токен с правами: `Workers Scripts: Edit`, `Account Settings: Read`,
  `Workers KV Storage: Edit` (для Durable Objects миграций хватает Scripts: Edit).

## 2. Локальный деплой

```bash
cd relay/worker
npm install

# токен и аккаунт — только в переменные окружения этой сессии
export CLOUDFLARE_API_TOKEN="новый_токен"
export CLOUDFLARE_ACCOUNT_ID="твой_account_id"

npx wrangler deploy
```

Вывод даст адрес вида:

```
https://meshchat-relay.<твой-субдомен>.workers.dev
```

Проверка живости:

```bash
curl https://meshchat-relay.<субдомен>.workers.dev/health
# {"ok":true,"service":"meshchat-relay","version":"2.4.0","ts":...,"colo":"FRA"}
```

## 3. GigaChat (необязательно)

Ключи Сбера живут **только в Cloudflare**, клиент их не видит:

```bash
npx wrangler secret put GIGACHAT_CLIENT_ID
npx wrangler secret put GIGACHAT_CLIENT_SECRET
# и общий секрет, чтобы чужой не жег твою квоту
npx wrangler secret put RELAY_KEY
npx wrangler deploy
```

Если ставил `RELAY_KEY`, тот же ключ нужно вписать в приложении:
**Поддержка → GigaChat → Relay URL** + ключ. Без него запросы вернут 401.

**Честное предупреждение про сертификат.** Сбер отдаёт API с сертификатом
Российского доверенного УЦ. Cloudflare Workers может отклонить такое TLS-соединение
(`fetch` в Workers строгий к цепочке). Если `/gigachat` вернёт ошибку сертификата —
варианты:

1. Поставить свой прокси на Fly.io (Node умеет подсунуть корневой сертификат Минцифры).
2. Оставить GigaChat в режиме «прямой вызов» в приложении (работает на Android-сборке,
   но требует, чтобы системный магазин доверял сертификату Сбера).
3. Жить на локальной базе знаний — она работает всегда.

Я не могу проверить это из песочницы: у меня нет доступа к `api.cloudflare.com`
и к API Сбера. Всё остальное в relay готово и протестировано логически.

## 4. Подключение в приложении

1. Настройки → **Сеть и транспорт** → вставить `https://...workers.dev`.
2. Нажать **Проверить** — появится «светофор»:
   - 🟢 RTT < 300 мс, тренд стабильный — канал здоров;
   - 🟡 RTT растёт или потери — сообщения уйдут в резерв;
   - 🔴 нет ответа — трафик не отправляется (fail-closed).
3. После подключения транспорты в чате перестанут быть «ДЕМО».

## 5. Что дальше (когда relay живой)

- Включить «гонку транспортов» (Cloudflare + Fly + P2P одновременно).
- Включить onion-only через Tor.
- Звонки WebRTC (сигналинг пойдёт через `/ws`).
- Реальные тикеты оператору: `POST /support/ticket` (добавим эндпоинт).

## 6. Стоимость

Free-план Cloudflare: 100 000 запросов/день и Durable Objects с щедрым лимитом —
для старта и первых сотен пользователей хватает с запасом. Платить не нужно.
